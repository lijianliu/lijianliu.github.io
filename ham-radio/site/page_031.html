💡 Series = same Current. Parallel = same Voltage.

📚 Key words

Series
Parts in one line, one after another. The same CURRENT flows through all of them.
Parallel
Parts side by side, each on its own branch. The same VOLTAGE is across all of them.
Component
A part in a circuit.
