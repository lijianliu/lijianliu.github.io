HOSTING
Extract this ZIP and upload these files together to a directory on your static
web host. Visit that directory's index.html over HTTP or HTTPS. Subdirectories
are supported; asset references are relative. Serve .js as JavaScript and .css
as CSS. No Node.js runtime, npm install, build, API key, database, or application
backend is required.

LOCAL PREVIEW
From the extracted directory, run:
    python3 -m http.server 8000
Then open http://localhost:8000 in a WebGL-capable browser.
Use an HTTP server rather than double-clicking index.html: browser security can
block JavaScript module imports over file://.

NETWORK AND STATE
The browser initially downloads HTML, CSS and JavaScript from your host.
Gameplay, 3D rendering and synthesized audio then run locally. The game makes
no AJAX/fetch requests, WebSocket connections, telemetry calls or server saves.
Progress lives in memory and resets on reload.

This export removes the original Google Fonts @import and uses system fonts
instead, so it needs no third-party network resources. The published original
has not been changed. Appearance can differ slightly because of the fonts.
The included Three.js engine contains generic loaders, but this game does not
use them to load remote assets. All room geometry is generated by game.js.

CONTROLS
WASD or arrow keys: move. Click a toy to interact. Touch controls are included.
The object selector also exposes all eight interactions.
