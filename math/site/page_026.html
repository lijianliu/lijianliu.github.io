26. One solution, no solution, or infinitely many?

E – Solving equations (Checkpoint 7) • 10 questions

💡 Solve it. If x disappears: a FALSE statement (7.5 = −8.75) → no solution. A TRUE statement (6 = 6) → infinitely many.

📚 Key words

One solution
You end with x = a number.
No solution
x cancels and you get something false, like 4 = −2.
Infinitely many
x cancels and you get something always true, like 6 = 6. Both sides are the same expression.
Same slope
Same x-coefficient on both sides is the warning sign that x will cancel.
