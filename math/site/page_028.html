💡 Both equations say "y = ...". Set the right sides equal, solve for x, then plug x back in to get y.

📚 Key words

System of equations
Two equations that must both be true at once.
Equal Values Method
If y = A and y = B, then A = B.
Solution
An ordered pair (x, y): the point where the lines cross.
Don’t stop at x!
Find y too, and write (x, y).

✏️ From the homework

HW 7-115d: y = ½x + 8 and y = ⅓x + 10 → ½x + 8 = ⅓x + 10 → x = 12, y = 14 → (12, 14).
