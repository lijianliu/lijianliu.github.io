💡 First distribute (multiply into the parentheses), then combine like terms, then solve.

📚 Key words

Distribute
a(b + c) = ab + ac. Multiply EVERY term inside.
Like terms
Terms with the same variable: 6.25x and −2.5x.
Watch the sign
−3(x − 2) = −3x + 6.
Simplify first
Clean up each side before solving.

✏️ From the homework

HW 7-106d: 6.25x + 7.5 − 2.5x = 3.75x − 8.75 → 3.75x + 7.5 = 3.75x − 8.75 → 7.5 = −8.75 → no solution.

✔A.x = −2
✘B.x = −1/5
✘C.x = 2
