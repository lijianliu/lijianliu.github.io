💡 ONE numeric variable → histogram / box plot / dot plot. TWO numeric variables → scatterplot. TWO categories → two-way table.

📚 Key words

Histogram
Bars showing how many data values fall in each interval.
Box plot
Shows median, quartiles, and range; great for "typical" value and spread.
Dot plot
A dot for each value above a number line.
Scatterplot
Shows the relationship between two numeric variables.
Two-way table
Compares two categorical variables.
