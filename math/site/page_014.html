14. What does the y-intercept mean? Does it make sense?

C – Line of best fit • 10 questions
Topics← Prev14 / 30Next →
💡 The y-intercept is the y-value when x = 0. Ask: "Does x = 0 even make sense here?"

📚 Key words

y-intercept
The starting value: y when x = 0.
Makes sense?
Check if x = 0 is possible AND the y-value is realistic.
Negative intercept
Often impossible in real life (negative cones, negative height).
Extrapolation
x = 0 may be far outside the data, so the model may break down.

C4-01
x = age (years), y = height (inches). Line: y = 2.5x + 20. What does the y-intercept mean?
✔A.When age is 0, height (inches) is 20.
✘B.For each 1 unit of age, height (inches) changes by 20.
✘C.When height is 0, age (years) is 20.
✘D.Height (inches) changes by 2.5 each unit.
💡 A newborn is about 20 inches long, so yes, it makes sense.
