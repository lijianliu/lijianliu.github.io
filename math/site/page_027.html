💡 Substitute the value for x on BOTH sides. If both sides are equal, it is a solution.

📚 Key words

Substitute
Replace x with the number (use parentheses for negatives!).
Solution
A value that makes the equation true.
Ordered-pair check
For a system, the point must work in BOTH equations.

✏️ From the homework

Is x = 6 a solution of 2x − 2 = −x + 16? Left: 2(6) − 2 = 10. Right: −6 + 16 = 10. Equal → yes.
